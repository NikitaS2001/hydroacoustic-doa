## 1. Постановка задачи

Проект отвечает на вопрос: можно ли надёжно определить азимут одного подводного источника по синхронным записям линейной решётки гидрофонов, размещённой подо льдом?

Исследуемый метод — компактный нейросетевой оцениватель, работающий с частотно-временным представлением многоканального сигнала. Его сравнивают с классическими алгоритмами пространственной фильтрации (MVDR/Capon, MUSIC) и диагностическим методом согласованного суммирования (Bartlett / Delay-and-Sum).

Проект устанавливает не только точность, но и условия, при которых результат имеет физический смысл, а также причины ошибок и отказов. Ни координаты датчиков, ни процедура обучения не создают информацию, отсутствующую в принимаемом сигнале.

## 2. Физические ограничения и условия однозначности

### 2.1. Зеркальная неоднозначность линейной решётки

Линейная решётка наблюдает проекцию направления прихода на свою ось. Два источника, симметричные относительно оси решётки, дают одинаковую картину межканальных задержек.

Следствие: для получения однозначного азимута необходим физически различимый сектор (например, известная полуплоскость расположения источника), общий для всех сравниваемых методов. Обзор на 360° принципиально невозможен без дополнительных априорных сведений.

### 2.2. Угол места

При неизвестном угле места даже выбранная полуплоскость не обеспечивает однозначность: наклонное прихождение волны искажает проекцию на горизонтальную ось решётки. Угол места должен быть:

- известен из геометрии эксперимента (фиксированные глубины источника и приёмников), либо
- ограничен настолько, чтобы его влияние на ошибку азимута было пренебрежимо мало для данной апертуры и полосы.

### 2.3. Дальнее поле

Приближение плоской волны допустимо, если расстояние до источника многократно превышает апертуру решётки на рабочих длинах волн. Для каждой конфигурации проверяют:

\[
R \gg \frac{L^2}{\lambda_{\min}}
\]

где \(R\) — дальность, \(L\) — апертура, \(\lambda_{\min}\) — минимальная рабочая длина волны. При невыполнении условия формулировку результата ограничивают наблюдаемой проекцией либо используют модель ближнего поля.

### 2.4. Многолучёвость подо льдом

Ледяной покров — не свободная поверхность. Отражение от льда зависит от частоты, угла скольжения, толщины и упругих свойств ледяной пластины. В результате может формироваться многолучевая структура, искажающая наблюдаемое направление. Классические методы (MUSIC, MVDR) в этих условиях могут деградировать без пространственного сглаживания; степень деградации и устойчивость нейросетевого метода к многолучёвости — вопросы, на которые отвечают измерения, а не априорные утверждения.

## 3. Функциональная схема тракта обработки

Для инженера-гидроакустика архитектура модели представляет собой цифровой тракт обработки сигналов, где веса фильтров и пространственных сумматоров не заданы аналитически, а обучаются на данных.

```text
[Многоканальный сигнал с гидрофонов]
        │
        ▼
 [1. Аппаратная калибровка и синхронизация]
        │  Устранение амплитудных/фазовых искажений трактов.
        │  Физическая задержка прихода между гидрофонами НЕ выравнивается.
        ▼
 [2. Спектральный анализ (STFT)]
        │  Переход в частотно-временную область.
        │  Сохранение действительной (Re) и мнимой (Im) компонент для работы с фазой.
        ▼
 [3. Канальная фильтрация (Энкодер)]
        │  Каждый гидрофон обрабатывается независимо, одними и теми же весами.
        │  Анализ временной структуры, выделение сигнала из шума.
        │  Координаты и межканальные связи на этом этапе НЕ используются.
        ▼
 [4. Пространственное объединение (Fusion)]  ◄── [Вектор измеренных координат]
        │  Сопоставление фаз между каналами при фиксированных частоте и времени.
        │  Учёт геометрии решётки, физической частоты и масок доступности.
        │  Последовательное усреднение: по датчикам → по частотно-временным позициям.
        ▼
 [5. Оценка направления / Контроль качества]
        │  Вычисление азимута θ ИЛИ фиксация отказа
        │  при численной вырожденности выхода.
        ▼
 [Результат: Азимут θ или Отказ]
```

Контрольная модель (абляция): идентичный тракт, в котором на вход блока [4] вместо реальных координат подаётся нулевой вектор. Физическая частота и маски сохранены. Сравнение основной и контрольной моделей позволяет проверить гипотезу о том, что система использует геометрию решётки. Различие в ошибках — свидетельство роли геометрии для данной конфигурации, но не универсальное доказательство превосходства над всеми нейросетевыми методами.

## 4. Требования к измерительному тракту

Численные параметры не назначаются по данному документу. Каждый параметр подтверждается испытанием тракта и протоколом до съёмки.

| Параметр | Подтверждение | Назначение |
| --- | --- | --- |
| Решётка: число гидрофонов, апертура, глубины, отклонение от линейности | Подводное обследование координат с оценкой неопределённости | Задержки, сектор, пределы метода |
| Источник: тип сигнала, полоса, длительность, глубина, дальность | Разрешение на излучение, пробная передача, журнал положений | Известный эталонный азимут |
| Регистратор: общий такт, синхронность каналов, частота дискретизации | Пробные многоканальные файлы, проверка межканального дрейфа | Сохранение фазы и задержки |
| Калибровка: АЧХ, ФЧХ, полярность, задержка каждого канала | Отдельные записи калибровки, контрольные суммы | Равный физический вход для всех методов |
| Подводная геометрия источника и приёмников | Единая система координат, оценка ошибки положения | Истинный азимут и проверка дальнего поля |
| Ледовая обстановка и безопасность | Решение квалифицированной службы; при небезопасных условиях съёмку не проводят | Осуществимость; безопасность важнее графика |
| Группы записей и разграничение доступа | План: фон до/после передач, независимые выезды, закрытый тест, журнал доступа | Исключение утечки данных в обучение |

Принципиально: сырые файлы сохраняются неизменными с контрольными суммами. Закрытые итоговые группы не используются ни для обучения, ни для настройки симулятора, ни для выбора конфигурации метода. Повторные передачи и окна внутри одного выезда не заменяют независимых выездов.

## 5. Тип источника и зондирующий сигнал

Тип зондирующего сигнала определяет структуру частотно-временного представления и требования к обработке. Окончательный выбор зависит от наличной аппаратуры, цели эксперимента и разрешений; он не фиксируется данным документом.

Рассматриваемые варианты:

| Вариант | Полоса | Потенциальные преимущества для DOA | Ограничения |
| --- | --- | --- | --- |
| Импульсный (взрыв, электроразряд) | Широкополосный | Высокое разрешение по задержке, простая идентификация | Невоспроизводимость формы, ограниченная энергия на ВЧ |
| ЛЧМ (chirp) | Широкополосный | Хорошее отношение сигнал/шум после согласованной фильтрации, воспроизводимость | Необходимость синхронизации и сжатия |
| Тональный непрерывный (CW) | Узкополосный | Максимальная точность фазовых измерений на одной частоте | Чувствительность к многолучёвости, фазовая неоднозначность при \(d > \lambda/2\) |
| Псевдошумовая последовательность (M-последовательность) | Широкополосный | Корреляционные свойства, помехоустойчивость | Сложность генерации и синхронизации |

Выбор фиксируется протоколом до съёмки по результатам испытания аппарата и пробных передач. До этого момента ни один вариант не считается основным.

## 6. Жизненный цикл модели: утверждённый минимум и исследовательская гипотеза

### 6.1. Утверждённый минимум

Обязательный цикл обучения, без которого модель не оценивается:

1. Обучение с учителем на разрешённой симуляции или размеченных данных разработки по известным углам. Настраиваются совместно Энкодер, Fusion и голова.
2. Контрольная модель без координат обучается отдельно, с той же архитектурой и тем же циклом, но с нулевым входом координатной ветви.

Этого достаточно для первого честного сравнения с классическими методами.

### 6.2. Исследовательская гипотеза: трёхэтапное самообучение

Трёхэтапная схема с маскированным предсказанием — исследовательская гипотеза, а не утверждённый план. Её цель — проверить, сокращает ли самообучение на неразмеченных записях разрыв между симуляцией и натурой, и если да, то на сколько. Гипотеза проверяется сравнением с контролем с нуля (та же архитектура, обученная сразу с учителем).

Проверяемые вопросы:

- Улучшается ли круговая ошибка и доля ответов на закрытых натурных группах по сравнению с контролем с нуля?
- Сохраняется ли выигрыш при переносе на симуляцию и обратно?
- Не является ли выигрыш артефактом конкретной реализации самообучения?

#### Этап 1: Самообучение Энкодера (канальный уровень)

Данные: разрешённые записи без угловых меток (фоновый шум, записи до/после пингов, записи из выездов разработки).

Метод: маскированное предсказание частотно-временных окон на одном гидрофоне. Часть окон маскируется; модель предсказывает их представления по видимым окнам.

Ожидаемый эффект (не гарантия): Энкодер адаптируется к спектральным характеристикам реального подлёдного шума и реверберации. Степень адаптации измеряется, а не предполагается.

#### Этап 2: Самообучение Fusion (пространственный уровень)

Данные: синхронные многоканальные записи без угловых меток.

Предварительное условие: на время Этапа 2 веса Энкодера фиксируются (замораживаются), чтобы пространственное предсказание не компенсировалось перестройкой канальных признаков.

Метод: маскированная решётка по принципу, аналогичному I-JEPA для изображений.

Аналогия с I-JEPA:

| Изображение (I-JEPA) | Решётка гидрофонов |
| --- | --- |
| Картинка, разбитая на патчи | Решётка из \(N\) гидрофонов |
| Патч изображения | Один канал на одной частотно-временной позиции |
| Маскировка части патчей | Отключение части каналов |
| Контекст видимых патчей + позиции | Контекст доступных каналов + координаты |
| Предсказание представлений замаскированных патчей | Предсказание представлений замаскированных каналов |

Пошаговый механизм:

1. Берём признаки всех \(N\) каналов от замороженного Энкодера: \(N\) каналов × \(T\) временных позиций × \(F\) частотных полос.
2. Случайным образом маскируем часть каналов. Замаскированные каналы помечаются в маске доступности как отсутствующие.
3. В блок внимания подаём только доступные каналы и их координаты.
4. Предиктор на основе контекста доступных каналов и координат замаскированных каналов предсказывает их представления.
5. Целевые представления получаются из целевого блока внимания (экспоненциально усреднённая копия основного блока):

\[
W_{\text{target}} \leftarrow \alpha \cdot W_{\text{target}} + (1 - \alpha) \cdot W_{\text{main}}
\]

Функция потерь: расстояние между предсказанным и целевым представлением замаскированных каналов.

Предиктор и целевой блок — вспомогательные компоненты обучения. Они не входят в итоговую модель и не используются при инференсе.

Замечание о доказательности. Заморозка Энкодера и EMA-копия блока внимания — стандартные технические приёмы против коллапса представлений. Сами по себе они не доказывают, что модель выучила пространственную физику. Доступность фазовой и задержечной информации проверяется отдельной диагностикой (например, диагностическими головами на замороженных признаках), а не фактом успешного самообучения. Перечень диагностических проверок приведён в §6.4.

#### Этап 3: Градуировка по известным углам (обучение с учителем)

Данные: разрешённая симуляция или размеченные данные разработки с известными углами.

Режим: после Этапа 2 все веса (Энкодер, Fusion, голова) размораживаются и совместно дообучаются по угловой ошибке. Этап 2 даёт инициализацию, а не окончательную фиксацию весов.

Результат: модель, готовая к оценке на закрытых группах.

### 6.3. Правила для всех этапов

- Самообучение проводится только на разрешённых данных разработки. Закрытые итоговые группы не используются.
- Предиктор, целевой блок и диагностические головы не входят в применяемую модель.
- Промежуточная диагностика Этапов 1 и 2 выполняется по §6.4 и не подменяет итоговую оценку на закрытых группах.
- Гипотеза считается проверенной, если сравнение с контролем с нуля даёт воспроизводимое различие на независимых группах. При отсутствии различия схема самообучения фиксируется как отрицательный результат, а не замалчивается.

### 6.4. Диагностика промежуточных представлений (Этапы 1 и 2)

Диагностика проводится только на разрешённых данных разработки. Закрытые тестовые группы не используются. Диагностические головы не входят в итоговую модель и служат только для анализа представлений.

Результаты диагностики не являются итоговым результатом по азимуту. Они используются для объяснения того, содержат ли промежуточные представления фазовую, временную и пространственную информацию, а также для принятия решений о качестве инициализации перед обучением с учителем.

#### Диагностика Этапа 1: канальный энкодер

1. Контроль коллапса представлений:
   - дисперсия по измерениям эмбеддинга;
   - эффективный ранг матрицы представлений;
   - внедиагональные элементы ковариационной матрицы;
   - средняя косинусная близость случайных пар токенов.

2. Качество маскированного предсказания частотно-временных окон:
   - ошибка предсказания на отложенных записях;
   - раздельная оценка по частотным полосам;
   - раздельная оценка по временным позициям;
   - сравнение со случайной инициализацией.

3. Линейные диагностические зонды:
   - наличие сигнала: сигнал / фон;
   - тип сигнала, если он определён протоколом разработки;
   - отношение сигнал/шум или класс SNR;
   - частотная полоса или центральная частота;
   - временная позиция окна.

4. Проверка отсутствия канального переобучения:
   - диагностический зонд на номер канала не должен показывать высокую точность, если это объясняется не физическими различиями трактов, а артефактами обучения.

5. Проверка чувствительности к временным сдвигам и фазовым искажениям:
   - контролируемые временные сдвиги;
   - контролируемые фазовые повороты;
   - оценка того, что энкодер не стал полностью инвариантен к задержкам и фазе.

#### Диагностика Этапа 2: Fusion

1. Качество предсказания замаскированных каналов:
   - ошибка предсказания на отложенных многоканальных записях;
   - раздельная оценка по каналам, частотам и временным позициям;
   - оценка при разных долях маскирования каналов.

2. Абляция координат:
   - предсказание с реальными координатами;
   - предсказание с нулевым вектором координат;
   - предсказание с перемешанными координатами.

   Отсутствие деградации при нулевых или перемешанных координатах является признаком того, что модель может не использовать геометрию решётки.

3. Проверка чувствительности к геометрии:
   - малые возмущения координат;
   - проверка плавности реакции модели;
   - проверка согласованности реакции с физической частотой и межканальным расстоянием.

4. Линейные диагностические зонды:
   - межканальная задержка;
   - знак проекции направления;
   - проекция направления или азимут, если разрешённые данные разработки имеют угловые метки.

5. Проверка устойчивости к пропускам каналов:
   - оценка плавности деградации представления при исключении части каналов;
   - сравнение с поведением модели при полном наборе каналов.

6. Проверка совместной перестановки каналов, координат и масок:
   - перестановка каналов вместе с координатами и масками не должна изменять физический смысл входа;
   - перестановка каналов без соответствующей перестановки координат должна рассматриваться как другой физический вход.

Интерпретация результатов диагностики фиксируется отдельно. Положительная диагностика не заменяет успешной итоговой оценки на закрытых группах, а отрицательная диагностика не является автоматическим доказательством непригодности метода без анализа причин.

## 7. Выход модели и механизм отказа

### 7.1. Базовый выходной контракт (утверждено)

Выход модели — два числа \((a, b)\), аппроксимирующие \((\cos\theta, \sin\theta)\). Азимут восстанавливается как

\[
\theta = \mathrm{atan2}(b, a).
\]

### 7.2. Функция потерь (утверждено)

Обучение минимизирует MSE по двум сырым компонентам \((a, b)\). Выход перед вычислением угла не нормируют. MSE не равна угловой ошибке в градусах; угловая ошибка — отдельная метрика оценки.

### 7.3. Механизм отказа (базовый уровень)

Отказ фиксируется в следующих случаях:

1. Полностью пустое наблюдение (все каналы или все позиции исключены масками).
2. Выходной вектор не проходит проверку конечности.
3. Численная вырожденность выхода (модуль вектора ниже заранее фиксированного порога).

Важно: малый модуль вектора — основание проверить численную вырожденность и усреднение фаз, а не прямое доказательство низкого отношения сигнал/шум. Интерпретация причины отказа — часть анализа, а не автоматический вывод модели.

### 7.4. Расширения, требующие модификации головы (не утверждено)

Следующие механизмы рассматриваются как возможные расширения и требуют изменения архитектуры головы:

- Переход к отрицательному логарифмическому правдоподобию распределения фон Мизеса с явным выходом концентрации \(\kappa\). Требует трёх выходов головы вместо двух.
- Использование концентрации как калиброванной меры уверенности и дополнительного условия отказа.

Эти расширения не входят в базовую оценку и вводятся только при отдельном обосновании и после фиксации базовой конфигурации.

## 8. Классические методы для сравнения

Все методы получают одинаковую измеренную геометрию, калибровку и работают на одних и тех же записях. Классические методы не настраиваются на тестовых данных.

| Метод | Статус | Что показывает |
| --- | --- | --- |
| Координатная нейросетевая модель | Обязательно | Основная оценка азимута с использованием геометрии |
| Та же структура без координат (контроль) | Обязательно | Проверка гипотезы о роли геометрической информации |
| MVDR / Capon | Обязательно | Адаптивная пространственная фильтрация: минимум выходной мощности при сохранении выбранного направления |
| MUSIC | Обязательно | Разложение на сигнальное и шумовое подпространства |
| Bartlett / Delay-and-Sum | Диагностика | Согласованное по задержкам суммирование; проверка фазовой согласованности и калибровки тракта |

Bartlett и Delay-and-Sum используются как один диагностический ориентир: их роли в данном проекте существенно пересекаются.

## 9. Моделирование распространения звука

Симуляция предназначена для разработки и отладки методов до натурных измерений. Она не заменяет натурную проверку.

Кандидат для расчёта распространения: BELLHOP или аналогичный код трассировки лучей / нормальных мод.

Критическое замечание: модель свободной поверхности или идеально отражающей плоскости не является моделью льда. Физически оговорённые контролируемые опыты с упрощённой границей допустимы для отладки тракта и проверок фазовой согласованности, но результаты таких опытов нельзя переносить на подлёдные условия.

Для количественных выводов о точности в подлёдных условиях необходимо учитывать:

- частотную и угловую зависимость коэффициента отражения от ледяного покрова;
- шероховатость нижней поверхности льда;
- упругие свойства ледяной пластины (толщина, скорость продольных и сдвиговых волн);
- формирование многолучевой структуры, отличной от открытой воды.

Модель ледяного покрова в симуляторе согласуется со специалистом по арктической акустике до начала генерации обучающих данных. Если согласование не достигнуто, это фиксируется как ограничение симуляции, а не обходится упрощённой границей.

## 10. Натурные подлёдные измерения (зима 2026–2027)

Зимние измерения — ключевое и обязательное событие проекта. При небезопасных ледовых условиях съёмка не проводится; отсутствие данных фиксируется как блокирующий фактор, а не подменяется симуляцией.

Требования к измерениям:

- Синхронные многоканальные записи с общей тактовой частотой.
- Управляемый источник с зафиксированными положениями и журналом пусков.
- Фактические подводные координаты источника и каждого гидрофона с оценкой неопределённости.
- Фоновые записи до и после серий передач.
- Не менее двух независимых выездов (разные дни / условия).
- Заранее выделенные закрытые тестовые группы, не используемые в разработке.

Данные, фиксируемые для каждой серии:

- Калибровка каналов (АЧХ, ФЧХ, задержка).
- Подводные координаты и их погрешность.
- Условия среды: толщина льда, глубина, температура, состояние дна.
- Неисправные или исключённые каналы.
- Тип и параметры зондирующего сигнала.

## 11. Метрики и критерии сравнения

Основная метрика:

- Круговая ошибка азимута — минимальное угловое расстояние между истинным и предсказанным направлением с учётом перехода через 0°/360°.

Отчётность по каждой группе:

- Медиана ошибки.
- 95-й процентиль (p95).
- Доля допустимых ответов (1 − доля отказов).
- Причины отказов.

Правила сравнения:

- Парное сравнение на одинаковых допустимых примерах; отказ получает ошибку 180°.
- Отдельно приводятся ошибки только состоявшихся ответов.
- Группы сравниваются с равным весом; повторные обучения и окна внутри выезда не увеличивают число независимых измерений.
- Симуляция и натура сравниваются раздельно; их отличие сообщается явно.
- При малом числе выездов выводы носят описательный характер.

Промежуточные метрики для Этапов 1 и 2:

- качество маскированного предсказания;
- контроль коллапса представлений;
- линейные диагностические зонды;
- абляция координат и проверка чувствительности к геометрии;
- устойчивость к пропускам каналов.

Эти метрики используются только для анализа представлений и принятия решений о качестве инициализации; они не заменяют круговую ошибку азимута на закрытых группах.

Проверки до интерпретации результата:

- Сохранность межканальной фазы и задержки после полного тракта.
- Корректность привязки каналов к координатам.
- Совместная перестановка каналов с координатами и масками.
- Наличие и анализ результатов промежуточной диагностики (§6.4), если применялись Этапы 1 и 2.

## 13. Глоссарий

### Акустика и измерения

| Термин | Пояснение |
| --- | --- |
| Азимут, DOA | Горизонтальный угол прихода звуковой волны относительно оси решётки |
| Угол места | Наклон направления прихода относительно горизонтальной плоскости |
| Зеркальная неоднозначность | Неразличимость двух направлений, симметричных относительно оси линейной решётки |
| Апертура | Расстояние между крайними гидрофонами решётки |
| Дальнее поле | Область, где волновой фронт приближённо плоский; проверяется по дальности и апертуре |
| Многолучёвость | Приход одного сигнала несколькими путями из-за отражений от льда и дна |
| Межканальная задержка | Разность времени прихода волны к разным гидрофонам; несёт информацию о направлении |
| Пространственная когерентность | Согласованность фаз сигнала между разными гидрофонами |
| Калибровка | Измеренная поправка на различия каналов: усиление, фаза, полярность, временная задержка |
| STFT, Re/Im | Короткое преобразование Фурье; действительная и мнимая части спектральных коэффициентов |

### Методы оценки

| Термин | Пояснение |
| --- | --- |
| MVDR / Capon | Адаптивный метод: минимизирует выходную мощность при сохранении чувствительности к выбранному направлению |
| MUSIC | Разложение корреляционной матрицы на сигнальное и шумовое подпространства; поиск пиков в шумовом спектре |
| Bartlett / Delay-and-Sum | Согласованное по задержкам суммирование; диагностический ориентир |
| Нейросетевой оцениватель | Обучаемый алгоритм, преобразующий многоканальный сигнал в азимут с использованием геометрии решётки |
| Отказ | Ситуация, когда метод не выдаёт корректного угла (пустое наблюдение, численная вырожденность, неконечный выход) |

### Обучение и данные

| Термин | Пояснение |
| --- | --- |
| Обучение с учителем | Настройка весов по записям с известным азимутом источника. Утверждённый минимум. |
| Самообучение (маскированное предсказание) | Предварительная настройка весов на записях без угловых меток. Исследовательская гипотеза. |

| Заморозка весов | Временная фиксация весов одного блока при обучении другого |

| Утечка данных | Запрещённое использование тестовых записей при обучении или настройке |
| Независимая группа | Отдельный выезд или серия измерений, не связанная с данными разработки |
